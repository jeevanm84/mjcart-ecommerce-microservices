# Security policy

## Supported versions

This educational project currently supports the latest commit on the `main` branch. There are no supported release branches yet.

## Report a vulnerability

Please do not open a public issue for a suspected vulnerability. Email **jeevanm.aws@gmail.com** with:

- the affected component and endpoint;
- steps to reproduce;
- potential impact;
- any suggested mitigation;
- whether the report may be credited publicly.

Please allow a reasonable amount of time for acknowledgement and investigation before public disclosure.

## Scope and expectations

MJ's Cart is an educational reference and should not be exposed to untrusted traffic or used with real customer data. Local defaults, sample Kubernetes secrets, simplified authorization, and deliberately compact services are not production security controls. See the [production-readiness learning path](docs/LEARNING_PATHS.md#experienced-production-readiness-review).
